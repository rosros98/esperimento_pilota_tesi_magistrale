# Experimental Data Analysis for Master Thesis 📊

This repository contains the pilot experiments developed during my Master’s thesis research project.
The main goal of the work was to **explore, clean, preprocess**, and **analyze multiple datasets** through different experimental phases in order to evaluate data quality, extract meaningful insights, and validate analytical approaches.

The repository is organized into several experiment folders, each containing datasets, preprocessing steps, data cleaning procedures, and analytical workflows.

## 🚀 Project Overview

The project focuses on the complete lifecycle of experimental data analysis, including:

* Raw data collection and organization
* Data cleaning and preprocessing
* Handling missing or inconsistent values
* Exploratory Data Analysis (EDA)
* Statistical observations and comparisons
* Experimental validation across multiple datasets

Each experiment was designed to test different methodologies and evaluate the impact of preprocessing and analysis techniques on the final results.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn (data visualization)
